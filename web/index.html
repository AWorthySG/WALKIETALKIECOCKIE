    About Cockie Talkie

    Each family channel is private: only people with its invite code can join. Audio is encrypted in transit; end-to-end encryption is not enabled. Audio is not recorded. Browser and phone settings can interrupt audio when the screen locks.

    Install Cockie Talkie

    Free to add to your Home Screen. No App Store or Google Play download needed.

    On iPhone or iPad

    1. Open this page in Safari.
    2. Tap Share, then Add to Home Screen. Scroll down if needed.
    3. Keep Open as Web App switched on if shown, then tap Add.
    4. Open Cockie Talkie using its new Home Screen icon.

    On Android

    1. Open this page in Chrome.
    2. Tap Install now below if available, and confirm the browser prompt.
    3. Alternatively, open Chrome’s ⋮ menu and choose Install app or Add to Home screen, then confirm.
    4. Open Cockie Talkie using its new Home Screen icon.

    If you opened this inside WhatsApp or another app, first use its menu to open in Safari or Chrome. Installation does not remove the phone’s background-listening limits.
